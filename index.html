Naiwa Motion Lab

把人的动作迁移到奶蛙身上：骨骼外面是一层软肉，在浏览器里实时做物理模拟。 Motion transfer onto 奶蛙 (Naiwa), simulated as soft flesh over a skeleton, live in the browser.

在线体验Live demo 代码Code 使用说明How to use

全部计算在你的浏览器里完成，摄像头画面和视频不会上传。Everything runs in your browser; camera frames and videos never leave your computer.

它做什么What it does

  1. 动作来源Motion sources

    摄像头、上传的视频，或 14 支预设动作（5 支从真实视频里提取，9 支程序生成）。MediaPipe 在本地估计人体姿态；上传的视频先整段分析，自动修正镜头运动和切镜。 Your webcam, an uploaded video, or one of 14 preset motions (5 captured from real videos, 9 procedural). MediaPipe estimates the pose locally; uploaded videos are analysed in full first, with camera motion and cuts corrected.

  2. 动作迁移Retargeting

    人的四肢方向搬到奶蛙短得多的骨骼上：滤波 → 目标 → 求解（IK 或带约束优化）→ 约束（四肢不进身体、关节限制）→ 脚踩实地面。 The person's limb directions mapped onto the frog's much shorter skeleton: filter → goal → solver (IK or constrained optimisation) → constraints (limbs outside the body, joint limits) → planted feet.

  3. 骨骼上的软体Soft body over a skeleton

    刚性骨骼作边界条件，外面是超弹性的软肉，双向耦合、动量守恒。可以戳、拖、拍、扔，看凹陷、晃动和衰减；材质可按身体部位分别设置。 Rigid bones as boundary conditions, hyperelastic flesh around them, coupled both ways with momentum conserved. Poke, drag, slap or throw it and watch the dents, the jiggle and its decay; the material can be set per body region.

两个实验室Two labs

动作迁移和模拟都是一个小核心循环加可替换的板块。实验室在页面上默认收起，打开后可以换算法、调参数、看读数、改代码。 Motion transfer and simulation are each a small core loop over replaceable blocks. The Lab is collapsed by default; open it to switch algorithms, set parameters, read the metrics and edit the code.

模拟器 · 9 个Simulators · 9

skeleton · flesh · target · coupling · collision · interaction · output · metrics

  • CPU 约束求解CPU constraint solver （默认）：Rapier 软体，PGS 求解，417 个粒子 / 1190 个单元。(default): Rapier soft bodies solved by PGS, 417 particles / 1190 cells.
  • GPU MPM：MLS-MPM（neo-Hookean + 粘性）。有 GPU 时用 WebGPU，没有时同一算法改用 Web Worker + SharedArrayBuffer 的 CPU 并行，页面显示当前后端。: MLS-MPM (neo-Hookean with viscosity). WebGPU when there is a GPU, otherwise the same algorithm on Web Workers over SharedArrayBuffer; the page shows which backend runs.
  • 算法库 7 个7 library algorithms：质点弹簧、PBD、XPBD、形状匹配、Projective Dynamics、隐式 FEM、FEM 加拉索。: mass–spring, PBD, XPBD, shape matching, Projective Dynamics, implicit FEM, FEM with tethers.

动作迁移 · 8 种Retargeters · 8

filter · goal · solver · constraints · output

  • 默认Default：方向拷贝 + 身体约束 + 脚踩地。: direction copy + body constraints + planted feet.
  • 滤波Filters：Kalman（视频用 RTS 平滑）、Savitzky–Golay。: Kalman (RTS smoothing for videos), Savitzky–Golay.
  • 求解Solvers：CCD、FABRIK、阻尼最小二乘、罚函数 Gauss–Newton 约束优化。: CCD, FABRIK, damped least squares, penalty Gauss–Newton constrained optimisation.

代码实验室Code lab

按板块查看源码，复制一份自己改，Ctrl+S 后在正在运行的模拟里热替换，出错自动回退；可以和内置板块对比指标。 Read any block's source, copy it, edit, press Ctrl+S to hot-swap it into the running simulation (it rolls back on errors), and compare it with the built-in block.

使用说明How to use

  1. 打开在线体验，奶蛙站在荷叶上。用鼠标或手指戳它、拖它、拍它、扔它。Open the live demo; the frog stands on a lily pad. Poke, drag, slap or throw it with the mouse or a finger.
  2. 在“动作”里选预设舞蹈、打开摄像头，或上传一段视频，奶蛙会跟着动。Under Motion, pick a preset dance, turn on the camera or upload a video; the frog follows.
  3. “手感”里换材质（果冻、麻薯、气球、布丁、橡皮）、调软硬和晃动时间，或打开慢动作、月球重力。Under Feel, switch materials (jelly, mochi, balloon, pudding, rubber), set softness and how long it wobbles, or turn on slow motion and moon gravity.
  4. 打开“实验室”换模拟器和动作迁移算法、看读数、编辑代码。Open the Lab to switch simulators and retargeters, read the metrics and edit the code.

完整的使用说明在页面里：点右上角的 ? 按钮，或按 ? 键。The full guide is inside the app: press the ? button at the top right, or the ? key.

本地安装和运行Install and run locally

需要 Node.js 18.19 以上（一键脚本会在缺少时安装）。本地运行还能用“本机 Lab”：检测到已登录的 Codex CLI 时，页面上出现“与 Codex 对话”和“用 Codex 优化”。 Needs Node.js 18.19 or newer (the one-click scripts install it when missing). Running locally also enables the local Lab: with a logged-in Codex CLI the page offers “Chat with Codex” and “Optimise with Codex”.

Windows

git clone https://github.com/ZhiqiLi-CG/naiwa-motion-lab.git
cd naiwa-motion-lab
install.cmd
start.cmd

也可以直接双击 install.cmd、start.cmd。Or double-click install.cmd and start.cmd.

Linux / macOS

git clone https://github.com/ZhiqiLi-CG/naiwa-motion-lab.git
cd naiwa-motion-lab
./install.sh
./start.sh

不需要 sudo；缺少 Node.js 时用 nvm 装到用户目录。No sudo; a missing Node.js is installed into your home with nvm.

手动：By hand: npm ci → npx vite → http://localhost:5180/ · 选项options: start --no-lab --no-open --port N --host --prod
